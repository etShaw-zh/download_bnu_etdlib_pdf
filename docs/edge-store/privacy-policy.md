# 小鸦PDF 隐私政策

更新日期：2026-10-14

本政策适用于小鸦PDF 的 Microsoft Edge 商店版本。小鸦PDF 由 GitHub 用户 etShaw-zh 独立开发，并非北京师范大学官方产品。

## 处理的信息及用途

扩展在用户点击导出，或在论文详情页点击“查看全文”时读取论文标题、作者及关联阅读页地址，用于跨标签页衔接导出任务和命名 PDF。扩展读取支持的论文阅读器页面及图像，在本地浏览器内存中生成 PDF，触发文件下载，不上传论文、PDF、标题或作者到开发者服务器。

为衔接详情页与阅读页，扩展将论文标题、作者、阅读页地址、标签页标识及导出任务状态暂存在浏览器本地的会话存储中。对应标签页关闭时清理关联记录；浏览器重启、扩展禁用或重新加载时，会话存储清空。生成后的 PDF 由用户通过浏览器及操作系统管理，扩展不会自动删除已下载的文件。

扩展不主动读取账号密码或 Cookie 内容。向论文网站获取页面图像时，请求可能使用浏览器现有的登录会话，以维持用户已具备的阅读权限。

## 网络访问和第三方服务

扩展访问北京师范大学学位论文服务系统 etdlib.bnu.edu.cn，读取用户有权限查看的论文内容。网站可能收到完成该请求所需的浏览器及网络信息。

打开扩展弹窗时，会向 api.github.com 请求本项目公开的最新 Release 信息，用于提示新版本。该请求不携带论文标题、作者或 PDF，但 GitHub 可收到正常网络请求中的 IP 地址和请求信息。用户点击更新、支持链接或论文系统入口时，将打开对应第三方网站，其数据处理由相应网站的政策约束。

扩展不设置广告或分析追踪，不出售用户数据，不执行从服务器获取的远程代码。

## 用户控制

用户可选择是否启动导出，并在 Microsoft Edge 的扩展管理页禁用或卸载扩展。用户可关闭论文标签页、重新加载扩展或重启浏览器，以结束相关任务并清理相应会话信息。已下载的 PDF 可由用户自行删除。

## 联系方式与政策更新

问题和反馈请通过项目 Issues 提交：https://github.com/etShaw-zh/download_bnu_etdlib_pdf/issues 。请勿在公开 Issue 中提交密码、论文全文或其他敏感内容。

扩展功能或数据处理方式发生变化时，将同步更新本政策。
