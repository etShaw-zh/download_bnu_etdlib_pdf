小鸦PDF 是面向 Microsoft Edge 的论文阅读辅助工具，帮助用户将北京师范大学学位论文服务系统中已有权限阅读的论文页面整理为 PDF，便于个人学习与科研阅读。本扩展为独立开发工具，并非北京师范大学官方产品。

主要功能
• 在论文详情页启动导出，自动打开全文阅读器。
• 读取详情页的论文标题与作者，使用“标题_作者.pdf”作为文件名。
• 自动逐页滚动加载论文页面，显示加载与图像获取的进度。
• 在阅读页面显示进度遮罩，减少导出期间的误操作。
• 在本地浏览器中生成 PDF，并触发下载。

使用方法
打开论文详情页或阅读页，点击扩展图标，再点击“开始加载并导出”。导出期间请保持阅读标签页在前台。若新标签页被拦截，请手动点击页面的“查看全文”。

适用范围与限制
仅支持 etdlib.bnu.edu.cn 中受支持的论文详情页和图像式全文阅读器；仍需满足网站的登录、网络访问和全文阅读权限。本扩展不提供论文资源，不绕过网站访问限制，也不支持所有 PDF 阅读器。直接打开阅读页时，若无详情页信息，将使用阅读器标题命名。

数据处理
论文图像和 PDF 在本地浏览器中处理，不上传至开发者服务器。论文信息仅用于跨页导出和文件命名。打开扩展弹窗时会访问 GitHub API 查询公开版本信息，不执行远程代码。

请尊重论文作者及学校的版权，仅在获得相应授权并符合网站规则的情况下使用，勿传播或商业使用导出的论文。
